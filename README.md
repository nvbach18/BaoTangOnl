# BaoTangOnl

A first-person virtual museum experience built with Three.js and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. On Windows PowerShell, use `npm.cmd` if
script execution policy prevents running `npm.ps1`.

## Controls

- `W`, `A`, `S`, `D`: move
- Mouse: look around
- `Shift`: sprint
- `Space`: jump
- `E`: interact with the museum entrance or elevator
- `Esc`: pause and open settings

The museum has four floors with two circular galleries per floor. Use the
central elevator to move between floors. Day/night and Vietnamese/English
settings are available from the pause menu.
